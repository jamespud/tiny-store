# 库存压测报告 (2026-07-31, 异步迁移后)

> 环境：单机 docker-compose-test 栈（gateway :8080 + inventory :13000 + PG/Redis/Nacos/Kafka）
> 工具：JUnit + Awaitility（超卖/幂等/confirm 锁竞争 DB 断言）+ k6（P95/吞吐）
> 对比基线：[2026-07-28 报告](./load-report-2026-07-28.md)（同步 Feign 版本）

## 1. 架构变化

```
同步版 (2026-07-28):
  Order -> Feign reserveCanonical (Redis+DB 原子) -> inventory

异步版 (2026-07-31):
  Order -> Feign preDeductRedisOnly (Redis only, sync 防超卖)
  Order -> Outbox INVENTORY_RESERVE_DB -> Kafka -> inventory consumer -> saveReservation (DB async)
```

## 6. 结论

- **不超卖**：异步迁移后 4 档全通过，Redis Lua 原子性保持。
- **幂等**：C<=5000 档 DB 三层断言全过；C=10000 网关完全饱和（0 成功），瓶颈在网关/单机栈，与同步版结论一致。
- **confirm 锁竞争**：N=500/1000 全 CONFIRMED、total=0、无死锁。
- **异步延迟**：1.2-8.6s（Outbox 5s 轮询 + Kafka + consumer，可接受）；P99 在低并发档（VUS=500）比同步版高 4x，高并发档（1000/5000）与同步版持平。
- **架构解耦**：Order 不再同步依赖 inventory DB 写入，仅同步 Redis 预扣（防超卖）。
- **栈瓶颈**：网关（8080）在 10000 并发时完全饱和（0 请求成功）；order 全链路 RPS 天花板约 1000。
